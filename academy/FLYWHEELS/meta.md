# Flywheel: Meta flywheel

**Cadence:** daily (evening)  
**Goal prefix (duplicate check):** `META FLYWHEEL RUN`  
**Runner:** `the meta flywheel runner on the project box` (on the project workspace)

## Purpose
The outermost loop: reflects on every other loop and task, benchmarks each against the repository, the live site and the task tracker, keeps deterministic per-loop performance data, and adds, retires, merges or re-times loops (its own settings included) on a nested halving ladder of cadences. North star: sales, traffic and the digital reconstruction of the manorial house and estate.

## Inputs
- the live schedule list
- per-loop run reports and logs
- repository, site and task-tracker activity

## Outputs
- per-loop metrics
- an apply list of cadence and loop changes
- one short weekly-style summary for the project lead

## Metric
north-star numbers week on week; loops retired, merged or added with evidence

## Report rules
One short message per run: north-star numbers, what changed in the loop set, the next biggest bet.

Built to the [flywheel schema](SCHEMA.md).
