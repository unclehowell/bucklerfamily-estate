# Flywheel: GitHub engagement

**Cadence:** every 10 minutes  
**Goal prefix (duplicate check):** `GITHUB ENGAGE RUN`  
**Runner:** `the GitHub engagement runner on the project box` (on the project workspace)

## Purpose
Watch every project repository for new issue and pull request comments, read the whole thread, reply in the thread with the house sign-off and do the work asked within the rules, or open and link a follow-up issue. GitHub is where collaboration on the project's work happens.

## Inputs
- new issue and pull request comments across the project repositories

## Outputs
- signed thread replies
- follow-up issues
- the work asked for

## Metric
comments answered, time to reply

## Report rules
Replies go in the thread itself, nowhere else.

Built to the [flywheel schema](SCHEMA.md).
