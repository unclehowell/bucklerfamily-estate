# Flywheel: Traffic flywheel

**Cadence:** daily  
**Goal prefix (duplicate check):** `TRAFFIC FLYWHEEL RUN`  
**Runner:** `the traffic flywheel runner on the project box` (on the project workspace)

## Purpose
The umbrella for new no-human-in-the-loop visitor channels and their measurement: measure clicks per channel, score, decide A/B tests, post within caps, syndicate blog copy, one directory listing and one newly researched practice per run.

## Inputs
- site analytics and tagged links
- the other growth loops' logs (inputs, not duplicates)

## Outputs
- posts within caps
- blog syndication with the link sent to every social channel
- A/B decisions
- a log row per action

## Metric
visitors per channel per day; winners and losers

## Report rules
Nothing routine; a message only on a win (a traffic jump or a sale) or a blocker only the project lead can fix.

Built to the [flywheel schema](SCHEMA.md).
