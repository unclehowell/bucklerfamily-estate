# StoryGraph community reading challenges: a reader-discovery route for a history e-book

Harvested 2026-11-05 (skills harvest). Before this, StoryGraph appeared only as a listing (goodreads-storygraph-listings-ebooks.md); challenges as a discovery route were not covered.

## What it is (checked 2026-11-05)
- StoryGraph hosts public reading challenges: prompts, a date range, and a shared list of the books participants file against each prompt. Anyone can open a challenge page and browse the books others added (r/TheStoryGraph thread, 2026).
- Public challenges are listed in a directory; the creator picks a category and adds keywords so readers can find it (mollychristiantyler.com StoryGraph guide). Private/friends-only challenges are not available (open request on StoryGraph's own roadmap).
- Chapter Adventure has ranked the most popular year-long StoryGraph challenges for three years running (2026 list, 28 Nov 2025): StoryGraph's own Genre Challenge, "StoryGraph Reads the World", 52 Book Club, Buzzword, POPSUGAR and others.

The lesson in the numbers: challenges tied to an existing audience (a podcast, a BookTuber, a book club) reach hundreds of readers; a challenge started from nothing stays at 1-14 people. Prompt-based nonfiction challenges sit at about 50.

## How to use it (author side, no outreach)
1. **Be findable for prompts, don't spam them.** Readers pick books to fit prompts like "a history book", "a book set in a country you have never visited", "a book under 100 pages", "a pairing". The book must be on StoryGraph with a clean description, page count, genre tags (history, nonfiction, Wales) and moods, so it shows when readers search.
2. **Read the prompt lists each December/January** (Chapter Adventure's yearly round-up and the 2027 nonfiction challenges) and note the prompts the book honestly fits. Use those exact prompt words in our own posts ("fits the 'short nonfiction' prompt").
3. **Only file a book against a challenge if we are a genuine participant** reading it. Filing our own title into strangers' challenges reads as spam; do not.
4. **Our own challenge only once there is an audience.** A Cedwyn-hosted challenge (e.g. "Read Wales 2027: 12 prompts") is worth making only alongside a channel that already has readers (newsletter, Instagram); otherwise expect the 1-14 participant range above.
5. **Measure:** a tracked link (utm_source=storygraph) in the book's description where StoryGraph allows a link, and in any post that cites a prompt. Kill rule: under 10 clicks in 60 days.

## How we apply it to Cedwyn
- Check the Cedwyn e-book listings on StoryGraph (goodreads-storygraph-listings-ebooks.md has the route): description, page count, tags history/nonfiction/Wales/Welsh, mood "informative". Fix the metadata only; that is our own listing.
- Nonfiction November (nonfiction-november-2026-weekly-themes-own-channel-pairing.md): abookolive's November StoryGraph challenge uses one-word prompts (root, puzzle, sample, frame). The free first edition fits "root" (family and place roots) and "sample" (short read). Name the prompt in the Week 3 own-channel post on 17 Nov; do not file the book into the challenge ourselves.
- January 2027: re-read Chapter Adventure's 2027 StoryGraph list and record the fitting prompts in the project workspace
- A Cedwyn-hosted "Read Wales 2027" challenge is a PROPOSAL for the queue (the project workspace), conditional on the newsletter passing 100 subscribers. It needs the Executive's go-ahead because it is a new public channel.
- Public text: never name the Executive; banned words apply; the book is a history of the place, not a verdict.
