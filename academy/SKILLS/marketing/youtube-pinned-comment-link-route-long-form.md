# YouTube pinned comment as the link route on long-form videos (not Shorts)

Harvested 2026-11-05. Before this file: 'pinned comment' / 'pin comment' had 0 skill-file hits in INDEX.md; youtube-shorts-non-clickable-links-related-video-bridge.md covers Shorts (links in Shorts comments and descriptions are not clickable), youtube-end-screens-related-video-playlists.md covers end screens. This file is the long-form comment slot.

## What the sources show
- **The feature (YouTube Help 9482367, read 5 Nov 2026):** in YouTube Studio, tap a comment > More > Pin "to highlight a comment at the top of your video's watch page"; pinning a new one unpins the old one; the commenter may be notified when you pin or reply. Only appears when viewing comments for one video.
- **Click effect (vendor/benchmark figures, not checked):** InfluencerFee's YouTube CTR benchmark guide (read): "Pinned comment CTR typically adds 15-35% to total sponsored link clicks compared to description-only placement"; links in the first 3 lines of the description "receive 3-8x more clicks than buried links"; a specific spoken call to action outperforms "check the description" by 2-4x. The page gives no sample size or method, so treat these as direction, not fact.
- **Practitioner testimony:** a LinkedIn post "3 obvious YouTube CTA fixes to increase your CTR by 30%" leads with "Put a CTA in the pinned comment. On mobile, people don't click on the description" (snippet, linkedin.com, not opened; no data shown). Impact+ 2026 YouTube guide: "pin a top comment with that link and a reason to click" (snippet).
- **Scope:** long-form only. On Shorts, URLs in comments are not clickable (see the Shorts file), so a pinned comment there can only say "full film on the channel".

## How to do it
1. **Write the comment as the channel**, 1-3 lines: a reason to click tied to that video ("The 1840 tithe map this clip shows, with the field names, is in the e-book"), then one tracked link. No price, no hype, no hashtags.
2. **Pin it immediately after publishing**, before the first viewers arrive; the pinned slot sits above viewer comments on the watch page and in the mobile comments sheet.
3. **Keep the description's first 3 lines matching** (shop line, documentary line), so the two placements reinforce each other; the pin is the mobile route, the description the desktop route.
4. **Track separately:** `utm_source=youtube&utm_medium=pinned_comment&utm_content=<video id>` vs `utm_medium=description`. After 30 days compare clicks per 1,000 views for each placement. The vendor claim (+15-35%) is the hypothesis being tested.
5. **Rotate when a better comment appears:** if a viewer asks a good question, reply with the source and pin that thread instead; pinning a real viewer exchange reads as care, not advertising.
6. **Never** pin in other people's videos (not possible) or post links in other channels' comments.
